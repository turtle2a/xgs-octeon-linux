OCTEP Linux driver and installer for OCTEON TX XGS appliances

Run a standard Linux distribution on OCTEON TX network appliances. The project provides the Linux OCTEP driver (DKMS), service scripts, an installer, and NAT/firewall setup for the tested XGS 2300, with optional, experimental NPU flow offload.

Source on GitHub · GPL-2.0-or-later

What it does

  • Builds and loads the octep driver with DKMS, so it survives kernel updates.
  • Brings up the NPU front ports as network interfaces (octep0 to octep9).
  • Routes all LAN ports out one uplink with per-subnet NAT, a default-drop firewall and DHCP (kea).
  • Optional NPU flow offload through an nftables flowtable (experimental; see the project documents).
  • Health checks, an uninstaller and an optional hardening service.

Quick start

git clone https://github.com/turtle2a/xgs-octeon-linux.git
cd xgs-octeon-linux
sudo sh ./install.sh

Read the README and the install requirements first, in particular the boot loader notes.
